# 居酒屋会計アプリ

<img src="kaikeikanri.png" width="120" alt="アイコン">

居酒屋での会計業務をスマートフォンで効率化するために開発したAndroidアプリです。  
チームごとの注文管理から月別売上の集計まで、実務で使えることを意識して設計・開発しました。

---

## 機能一覧

- **チーム管理** - お客様のグループごとにチームを作成して注文を管理
- **メニュー登録** - 飲み物・食べ物をカテゴリ別に登録、値段の変更も可能
- **注文管理** - 商品タップで注文追加、数量の修正・削除も対応
- **営業日管理** - 午前6時切り替えルールで日またぎの注文も正確に記録
- **売上履歴** - 月別・日別で売上を確認、内訳の閲覧も可能
- **消費税計算** - 設定オンで全商品に10%を自動上乗せ
- **原価・純利益管理** - 原価を登録して純利益を自動計算
- **バックアップ・復元** - JSONファイルでデータをエクスポート・インポート
